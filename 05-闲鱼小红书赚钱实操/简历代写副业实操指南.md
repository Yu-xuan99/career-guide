## 三、小红书运营策略

### 内容方向
| 类型 | 示例标题 |
|------|---------|
| **干货教程** | "简历这样写，面试邀请多3倍" |
| **前后对比** | "修改前vs修改后，同一份简历通过率差10倍" |
| **避坑指南** | "简历中HR最讨厌的5个写法" |
| **行业模板** | "互联网产品经理简历模板分享" |
| **客户案例** | "帮零经验应届生拿到字节面试的简历长什么样" |
| **数据分享** | "修改了1000份简历后发现的问题" |

### 小红书爆款标题公式
```
1. 数字型："简历通过率从10%到90%，我只改了3个地方"
2. 痛点型："投了100份没回应？你的简历犯了这5个致命错误"
3. 对比型："985硕士简历vs双非本科简历，差距在哪里"
4. 身份代入型："作为HR，我看到这种简历直接扔掉"
5. 案例型："用这个模板，3天收到12个面试邀请"
```

### 小红书引流到私域
1. 笔记末尾引导："需要简历模板的评论区扣1"
2. 私信发微信号（注意不要被系统检测）
3. 建"简历交流群"沉淀用户
4. 朋友圈每天发客户好评+干货

## 五、服务流程SOP

### 标准5步流程

**第1步：需求沟通（10-15分钟）**
- 了解客户基本情况（学历、工作年限、岗位方向）
- 索要现有简历或经历描述
- 确定目标行业和岗位
- 告知预期交付时间

**第2步：信息整理（15-20分钟）**
- 研究目标岗位JD，提取关键词
- 整理客户经历素材
- 套用对应行业模板框架

**第3步：AI生成+人工优化（30-45分钟）**
- 使用AI工具生成初稿
- 人工校对、优化、补充细节
- 确保数据合理、逻辑通顺

**第4步：排版交付（10-15分钟）**
- 使用专业工具排版
- 输出Word+PDF双格式
- 附上面试注意事项

**第5步：跟进修改**
- 客户反馈后24小时内修改
- 收集好评截图

## 七、常见问题与应对

| 客户常见问题 | 回答策略 |
|-------------|---------|
| "能保证拿到面试吗？" | 不能100%保证，但能显著提升通过率（展示历史好评） |
| "为什么要这么多钱？" | 强调专业价值：HR视角+行业经验+数据量化+无限修改 |
| "不满意怎么办？" | 免费修改直到满意，建立信任 |
| "我的经历太普通了" | 每个人都有亮点，我们的专业就是帮你挖掘出来 |
| "能不能便宜点？" | 对标市场价，强调品质和修改次数，可适当优惠首单 |

## 九、风险提示

1. **不要承诺100%拿到面试/offer** — 有法律风险
2. **不要帮客户编造经历** — 诚信底线
3. **保护好客户隐私** — 简历含大量个人信息
4. **注意平台规则** — 不要在小红书直接发微信号
5. **按时交付** — 逾期容易差评
6. **合理定价** — 不要打价格战，做品质取胜
