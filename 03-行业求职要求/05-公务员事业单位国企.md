# 公务员/事业单位/国企求职要求

## 一、体制内简历的核心特点

| 维度 | 国企 & 机关单位 | 外企 & 私企 |
|------|----------------|-------------|
| **基本信息** | 需要填充丰富（政治面貌、籍贯、性别、民族等） | 一般只需姓名、邮箱、电话 |
| **实习经历** | 非常看重与岗位相关的实习经历 | 更看重综合素质与企业文化匹配度 |
| **荣誉奖励** | 数量越多越好，尤其看重学生干部、优秀党员等 | 更看重含金量而非数量 |
| **篇幅** | 一页中文简历即可 | 最好中英文各一页 |

---

## 二、简历必备模块

### 1. 个人信息
- 姓名（大号字体）、手机号、邮箱、近期正装证件照
- **体制内加写**：政治面貌（党员加分项）、籍贯（本地优先）、性别、出生年月

### 2. 求职意向
- 必须明确、唯一，切忌模糊空泛

### 3. 教育经历
- 格式：`时间段 + 学校名称 + 专业名称 + 学历`，从本科起由近到远
- 绩点高的可标注

### 4. 实习与工作经历（核心）
- 用 **STAR法则** 描述
- 体制内侧重：组织协调能力、公文写作、政策理解

### 5. 荣誉奖励
- 按「国家级 → 省级 → 校级」排序
- 重点突出：三好学生、优秀党员、优秀学生干部

### 6. 自我评价
- 词语概括 + 简单举证，避免空话套话

## 三、考试体系

### 公务员
| 科目 | 内容 |
|------|------|
| **行测** | 言语理解、数量关系、判断推理、资料分析、常识判断 |
| **申论** | 阅读理解、综合分析、提出对策、文字表达 |
| **专业科目** | 部分岗位加试（如公安、审计、金融监管等） |

### 事业单位
| 科目 | 内容 |
|------|------|
| **职测** | 类似行测，难度稍低 |
| **综应** | 岗位分类（A类管理/B类社科/C类自科/D类教师/E类医疗） |
| **公基** | 政治、法律、经济、文史、科技等 |

### 国企
- 类似行测 + 专业知识测试
- 企业文化了解（如中国移动、国家电网等有专属题库）
- 部分国企考英语

---

## 四、面试形式

### 结构化面试
- 标准问题 + 标准评分
- 考察：综合分析、组织协调、应急应变、人际关系、语言表达
- 一般3-4道题，15-20分钟

### 无领导小组讨论
- 8-12人一组
- 给定话题自由讨论
- 考察：团队协作、领导力、表达能力、逻辑思维

---

## 五、7个关键原则

1. **一页纸搞定**：简洁有力
2. **模板简约大方**：颜色统一、排版干净
3. **突出关键信息**：国家级奖项、学术成果优先
4. **绝对真实**：不接受造假
5. **检查低级错误**：不写错公司名/岗位名
6. **PDF格式投递**
7. **选对发送时间**：建议早上8:00-8:50

---

## 六、投递规范

| 项目 | 规范 |
|------|------|
| **邮件标题** | 应聘xx职位+姓名+学校 |
| **简历文件命名** | 应聘xx职位+姓名+学校 |
| **附件格式** | PDF |
| **邮件正文** | 礼貌称呼 + 简短自我介绍 + 明确求职意向 |

## 七、常见体制内岗位举例

| 类型 | 热门岗位 |
|------|---------|
| **选调生** | 定向选调（985/211）、普通选调 |
| **国考** | 税务、海关、铁路公安、统计局 |
| **省考** | 乡镇/街道、市场监管局、法院/检察院 |
| **事业单位** | 高校行政、中小学教师、医院行政、科研院所 |
| **国企** | 国家电网、中石油/中石化、三大运营商、国有银行 |
