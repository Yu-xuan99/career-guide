# 医疗/护理行业求职要求

## 一、医生岗位

### 典型岗位分类
| 岗位类型 | 主要职责 |
|-----------|----------|
| 门诊/住院医师 | 日常门诊、急诊出诊、抢救等临床工作；家医签约及慢病管理；健康教育 |
| 院前急救医生 | 院前急救、危急重病症初步诊治与抢救护理；各类重大活动医疗保障 |
| 健康管理中心医师 | 体检、主检、体检项目制定、检后咨询、健康讲座、健康管理 |
| 放射/影像医师 | 独立完成普放、CT、MRI诊断报告；科研和教学工作 |

### 招聘条件（2025年常见要求）
| 条件维度 | 具体要求 |
|----------|----------|
| **学历** | 本科及以上（三甲医院多要求硕士/博士）；部分岗位博士优先 |
| **专业** | 临床医学相关专业（内科学、外科学、影像医学等） |
| **资格证书** | 医师资格证、执业医师证、住院医师规范化培训合格证（必备） |
| **年龄** | 初级一般≤35岁；中级≤40岁；副高≤45岁；正高≤50岁 |
| **经验** | 部分岗位要求三甲医院3-5年以上临床工作经历 |
| **科研能力** | 有SCI论文发表、参与科研课题经验者优先（三甲教学医院尤其看重） |
| **素质要求** | 责任心、应急处理能力、团队协作精神、医患沟通能力 |

## 二、护士岗位

### 典型岗位职责
1. 执行医嘱，完成打针、输液、给药、采血等基础护理操作
2. 观察患者病情变化，监测生命体征
3. 规范书写护理记录、交班报告
4. 做好患者的基础护理和心理护理
5. 做好危重患者抢救工作及抢救物品、药品的准备和保管
6. 执行消毒隔离制度，预防院内感染
7. 协助医师进行治疗工作，负责采集检验标本
8. 办理入院、出院、转科、转院手续

### 招聘条件
| 条件维度 | 具体要求 |
|----------|----------|
| **学历** | 护理学类专业，本科及以上学历（部分基层岗接受大专） |
| **专业** | 护理学、助产等相关专业 |
| **资格证书** | 护士执业资格证书（必备）、护师/主管护师职称、CPR/BLS认证 |
| **年龄** | 一般≤25-35岁（初级岗）；护理管理岗可放宽至45岁 |
| **经验** | 有三甲医院实习/工作经验者优先 |
| **能力要求** | 沟通表达能力、团队协作精神、应变能力 |
| **素质要求** | 责任心、耐心、爱心、服务意识、心理承受能力 |

## 四、面试技巧要点

| 问题类型 | 应对策略 |
|----------|----------|
| **专业病例分析** | 病例背景→诊断难点→处理过程→结局与反思 |
| **医患沟通场景** | 安抚情绪→解释依据→提供选项→情感共鸣 |
| **职业规划** | 个人专长 + 医院需求 + 具体行动计划 |
| **团队协作案例** | 跨科室协作举例，使用STAR法则 |

### 加分技巧
- 量化成果：用具体数字（例数、成功率、时间缩短）替代模糊描述
- 携带材料：纸质简历5份以上、资格证书复印件、学术成果证明
- 面试后24小时内发送感谢信

## 五、2025年求职趋势

1. 三甲医院医生岗普遍要求博士，护士岗以本科起步
2. SCI论文、科研项目经历成为三甲医院重要加分项
3. 规培证是医生求职必备条件
4. 专科护士培训证书（老年护理/儿科护理/ICU等）显著提升护士竞争力
