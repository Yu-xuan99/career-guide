- 有项目现场管理、调试经验（社招）

## 三、建筑/房地产/工程

### 项目经理求职要求
| 要求类别 | 具体内容 |
|----------|----------|
| **学历** | 本科及以上，土木工程、建筑学、城乡规划等相关专业 |
| **职称** | 中级工程师及以上；高级工程师优先 |
| **工作经验** | 8年以上房地产行业经验，至少2个房地产项目全周期管理经验 |
| **执业资格** | 一级注册建造师、造价工程师、注册监理工程师等优先 |
| **软件技能** | AutoCAD、广联达、Revit（BIM） |

### 核心能力
- 独立的决策能力和大型房地产项目综合管理能力
- 精通地产计划运营管理（投资、安全、质量、进度、成本控制）
- 出色的沟通协调能力、政府公关能力
- 项目报批报建、竣工验收等全流程管理经验

### 简历项目示例

```
"负责上海某大型商业综合体项目土建施工管理，总投资20亿元，建筑面积达30万平方米；
主导施工组织设计优化，将施工进度提前8%；
土建工程一次验收合格率提升至99%。"
```
