# 销售/市场/产品/运营求职要求

## 一、销售/市场岗

### 核心要求
- **核心标准**：你能带来多少可衡量的商业价值
- 没有数字支撑的简历初筛即淘汰

### 简历策略

| 板块 | 写法要求 |
|------|----------|
| **业绩数据** | 每条经历首条bullet point必须是核心业绩："全年完成销售额3200万，达成率142%，45人团队排名第3" |
| **销售闭环** | 客户开发（获客数量/渠道）→商机管理（转化率/销售周期）→客户成功（续约率/客单价） |
| **市场岗ROI** | ❌ "策划执行了3场大型活动" → ✅ "统筹50万预算举办行业峰会，吸引1200名精准客户，产生SQL 300条，ROI达1:4.5" |

### 关键词侧重
- **销售岗**：配额达成率、客户拓展、大客户管理、销售漏斗、赢单率
- **市场岗**：获客成本(CAC)、转化率、品牌曝光、内容营销、增长黑客

## 二、产品岗

### 核心要求
- 同时证明：懂用户 + 懂数据
- 项目经历按「问题-方案-验证」逻辑展开
- B端/C端/数据产品侧重点不同

### 简历模板
```
"通过用户调研发现新用户次日流失率高达60%，
主导优化onboarding流程，设计新手引导任务体系，
7日留存率提升至45%，月活用户增长30%。"
```

### 关键词
需求分析、用户研究、原型设计、产品迭代、数据驱动、PRD撰写、A/B测试

## 三、运营岗

### 运营分类
| 类型 | 重点 |
|------|------|
| **用户运营** | 分层策略、LTV提升、用户生命周期管理 |
| **内容运营** | 爆款率、分发效率、内容矩阵 |
| **活动运营** | 创意执行、转化效果、ROI |
| **社群运营** | 社群规模、活跃度、变现转化 |

### 简历示例
```
"搭建用户分层体系，通过RFM模型将用户分为4个层级，
针对高价值用户制定VIP服务计划，核心用户月留存率从45%提升至72%，
年度LTV提升58%。"
```

## 四、职能岗（HR/行政/财务）

### HR岗
| 岗位 | 简历示例 |
|------|---------|
| HR招聘 | "搭建人才pipeline，关键岗位招聘周期从45天缩短至28天，试用期通过率提升至92%" |
| HRBP | "深入业务线，设计销售团队激励方案，推动季度业绩超额完成30%" |

**关键词**：人才盘点、组织发展(OD)、绩效管理、雇主品牌、人力数据分析

### 行政岗
```
"通过供应商重新谈判和流程优化，年度行政费用降低18%，
优化办公空间利用率提升30%。"
```

**关键词**：流程优化、成本管控、资产管理、会务统筹

### 财务/会计岗
| 岗位 | 要求 |
|------|------|
| **学历** | 会计/审计/财务管理相关专业本科及以上 |
| **证书** | 初级会计职称（必备）、CPA/中级会计职称（加分） |
| **技能** | 熟练使用用友/金蝶/SAP、Excel精通 |

### 法务岗
```
"主导合同模板标准化项目，平均审核周期从3天缩短至4小时，
年度规避潜在纠纷损失约200万元。"
```

**关键词**：合同审查、合规管理、知识产权、争议解决
