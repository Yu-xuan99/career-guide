# 金融/银行/证券/保险行业求职要求

## 一、行业岗位分类

### 银行类
| 岗位 | 主要职责 | 薪资范围 |
|------|---------|---------|
| 银行柜员 | 对公/对私客户业务处理、票据审核、账户管理、现金管理 | 8K-15K/月 |
| 客户经理 | 存量客户维护与新客户拓展、理财产品销售、信贷业务申报 | 12K-25K/月 |
| 大堂经理 | 引导客户办理业务、维护银行秩序、理财销售与推荐 | 10K-18K/月 |
| 风控专员 | 贷前调查、风险评估、信用审核、反欺诈 | 15K-30K/月 |
| 科技菁英(银行IT) | 系统开发、数据平台、信息安全 | 20K-40K/月 |

### 证券/投资类
| 岗位 | 主要职责 | 薪资范围 |
|------|---------|---------|
| 证券分析师 | 宏观经济分析、行业研究、撰写分析报告、量化模型研发 | 15K-35K/月 |
| 投资银行 | 企业上市/并购/再融资项目承揽承做、尽职调查 | 20K-50K/月 |
| 基金经理 | 投资组合管理、资产配置、风险控制 | 30K-80K/月 |
| 量化研究员 | 量化策略开发(事件驱动、多因子选股)、回测优化 | 25K-50K/月 |

### 保险类
| 岗位 | 主要职责 |
|------|---------|
| 精算师 | 保险产品定价、准备金评估、风险建模 |
| 核保/核赔 | 风险评估、保单审核、理赔判定 |
| 保险代理人 | 客户开发、保单销售、售后服务 |

## 二、硬性求职要求

| 条件维度 | 具体要求 |
|----------|---------|
| **学历** | 本科及以上（985/211优先），金融学、经济学、会计学等相关专业 |
| **必备证书** | 证券从业资格证、基金从业资格证、期货从业资格证 |
| **加分证书** | CFA（特许金融分析师）、FRM（金融风险管理师）、CPA（注册会计师）、ACCA |
| **技能** | Excel/PPT精通、SQL/SPSS数据分析、Bloomberg/Wind金融终端操作 |
| **英语** | CET-6 425+，部分岗位要求IELTS 6.5+或流利英文工作能力 |
| **实习** | 有银行、券商、基金公司实习经历者优先 |

## 三、各方向关键词侧重

### 投行/行研
- 财务建模、估值分析（DCF/可比公司/先例交易）
- 尽职调查、IPO流程、并购重组
- Wind/Bloomberg/Pitchbook
- 行业研究框架、公司深度报告撰写

### 风控/合规
- 信用风险评估、市场风险管理
- 反洗钱(AML)、巴塞尔协议
- 压力测试、VaR模型
- 监管合规、内控制度建设

### 量化/交易
- Python/R/MATLAB
- 多因子模型、统计套利
- 回测框架、高频交易系统
- 机器学习在金融中的应用

### 财务/审计
- 合并报表、税务筹划
- 内部控制、审计程序
- SAP/Oracle Financials
- IPO审计、尽调经验

## 五、2025年金融求职趋势

1. **学历门槛持续提高**：投行/行研岗普遍要求硕士起点，头部机构偏好清北复交+海外名校
2. **证书硬门槛化**：证券从业资格证是底线，CFA/CPA从"加分"变成"标配"
3. **科技+金融复合型吃香**：懂Python+SQL+金融的候选人薪资溢价30%+
4. **量化岗位爆发**：私募量化规模破万亿，策略研究员供不应求
5. **ESG/绿色金融是新赛道**：越来越多机构设立ESG研究岗位
