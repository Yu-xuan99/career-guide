# 教育/培训/教师行业求职要求

## 一、岗位分类与要求

### K12/中小学教师
| 条件 | 要求 |
|------|------|
| **学历** | 本科及以上，师范类相关专业优先 |
| **资格证书** | 对应学段教师资格证（必备） |
| **普通话** | 语文教师二甲以上，其他学科二乙以上 |
| **其他** | 省师范生技能大赛获奖、党员、学生干部经历加分 |

### 高校教师/辅导员
| 条件 | 要求 |
|------|------|
| **学历** | 硕士及以上（教学岗通常要求博士） |
| **辅导员** | 硕士及以上，中共党员，教育学/心理学/思政等专业 |
| **其他** | 科研成果、论文发表（教学岗必备） |

### 培训机构讲师
| 条件 | 要求 |
|------|------|
| **学历** | 本科及以上，相关学科专业 |
| **经验** | 有教学经验者优先，无经验可从助教做起 |
| **能力** | 表达能力强、课堂感染力、续班率意识 |

## 二、简历撰写核心要点

### 10大核心原则
1. 求职意向明确：岗位类型 + 城市 + 学段（小学/初中/高中）
2. 教育背景突出GPA/排名/荣誉
3. 教学实践经历用证据化表达（学生成绩变化、续班率、满意度）
4. 突出国家级/省级荣誉证书
5. 简历照片需写实、职业化，排版简洁
6. 分岗位多版本：公办教师 vs 培训机构 vs 高校辅导员分别制作
7. 量化成果：学生平均提分XX分、班级排名提升XX名、续班率XX%
8. 熟悉新课程理念、当地教材版本
9. 教育学、心理学相关知识储备
10. 技能证书模块：教师资格证 > 普通话等级 > 英语等级 > 计算机等级

## 四、面试与试讲技巧

### 试讲（模拟授课）核心要点

| 要点 | 具体建议 |
|------|----------|
| **备课** | 认真审题，把握题签关键信息，切忌题不对文 |
| **板书** | 务必整洁清晰，直观展现一堂课的思维脉络 |
| **教学创新** | 融入个人特长与创新方法 |
| **基本功** | 英语教师每日至少20分钟语音训练 |
| **演练方式** | 录制视频自评、模拟演练 |
| **时间控制** | 精准把控试讲时长，突出重点环节 |

### 面试高频问题
- "为什么选择我们学校？"→ 结合学校特色、教育理念
- "你的教学理念是什么？"→ 以学生为本、因材施教
- "如何处理课堂管理问题？"→ 举例具体策略
- "你的职业规划？"→ 教学→教研→学科带头人

### 面试加分技巧
- 着装商务正装或得体职业装
- 现场携带多份简历、证件及作品集
- 回答问题时站在教师角度思考，以学生为本
- 结构化应答，用STAR法则回答行为面试题

## 五、不同教育岗位求职策略

### 公办学校教师
- 关注教育局官网/人社局招聘公告
- 准备教育综合知识+学科专业知识笔试
- 结构化面试+试讲
- 提前了解编制情况（事业编 vs 合同制）

### 培训机构教师
- 看重试讲表现和教学感染力
- 强调续班率和学生提分数据
- 了解主流培训品牌（好未来、新东方、猿辅导等）

### 高校辅导员
- 硕士学历+中共党员是门槛
- 笔试：辅导员专业知识+思政理论+公文写作
- 面试：结构化+案例分析+谈心谈话模拟
