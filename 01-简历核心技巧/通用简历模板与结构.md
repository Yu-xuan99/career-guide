# 通用简历模板与结构

## 一、简历黄金结构（所有行业适用）

```
┌─────────────────────────────────┐
│  1. 个人信息（姓名/电话/邮箱/求职意向）    │
│  2. 教育背景（倒序，绩点/奖学金/相关课程）  │
│  3. 实习/工作经历（STAR法则 + 数据量化）   │
│  4. 项目经历 / 校园经历              │
│  5. 技能证书（按岗位优先级排序）         │
│  6. 自我评价（3句话，突出岗位适配性）     │
└─────────────────────────────────┘
```

> 核心原则：单页最佳（5年以内经验），黑白极简设计，保存为PDF，文件命名规范为 `岗位-姓名-工作年限.pdf`

---

## 二、三大高频场景模板

### 模板A：应届生通用

```
个人信息 → 教育背景(突出绩点/奖学金/相关课程)
→ 实习经历(STAR法则+数据量化)
→ 校园经历(组织能力/执行力)
→ 技能证书(按岗位优先级排序)
→ 自我评价(3句话突出适配性)
```

### 模板B：职场跳槽

```
个人信息 → 工作经历(倒序，重点近2份，数据量化业绩)
→ 核心技能(如运营岗"用户增长/数据分析"，技术岗"Python/LangChain")
→ 项目经历(核心项目+解决问题能力)
→ 自我评价(职场经验与岗位匹配度)
```

### 模板C：实习转正式

```
个人信息 → 实习经历(当前实习重点写，日常工作成果+岗位契合度)
→ 技能提升(实习期间掌握的岗位相关技能)
→ 校园/其他经历(辅助能力体现)
→ 自我评价(对企业的认可度+留任意愿)
```

## 三、30秒快速定制法（适配任意岗位）

1. **建立母版简历库**：包含全部经历/技能/项目/数据的完整素材库，按技能类别整理
2. **针对具体岗位三步微调**：
   - 关键词替换：将JD高频技能词融入技能描述和项目经历
   - 经历重排：最相关的3-4条前置，弱化不相关内容
   - 数据强调：根据岗位核心诉求调整量化指标呈现顺序

## 四、简历避坑清单

| ❌ 常见错误 | ✅ 正确做法 |
|------------|------------|
| 一份简历海投所有岗位 | 每个岗位定制版本，"一岗一版" |
| 花哨图形/表格/色块 | 黑白文字+标准字体+清晰标题 |
| 经验5年以上超两页 | 5年内严格一页，10年内最多两页 |
| 文件名"简历.pdf" | 改为"岗位-姓名-工作年限.pdf" |
| "流水账式"描述经历 | STAR法则 + 量化数据 |
| 罗列所有接触过的技术 | 只保留JD明确要求和近期使用的 |
| 自我评价空洞无物 | 3句话突出岗位适配性 |
| 编造经历 | 诚信是底线，面试追问必露馅 |
| 用Word格式投递 | 保存为PDF再投递 |
| 邮件主题是空的 | 姓名+岗位+工作年限 |

## 五、体制内 vs 私企简历差异

| 维度 | 国企 & 机关单位 | 外企 & 私企 |
|------|----------------|-------------|
| 基本信息 | 需要填充丰富（政治面貌、籍贯、性别、民族等） | 一般只需姓名、邮箱、电话 |
| 实习经历 | 非常看重与岗位相关的实习经历 | 更看重综合素质与企业文化匹配度 |
| 荣誉奖励 | 数量越多越好，尤其看重学生干部/优秀党员 | 更看重含金量而非数量 |
| 篇幅 | 一页中文简历即可 | 最好中英文各一页 |

## 六、简历投递规范

| 项目 | 规范 |
|------|------|
| 邮件标题 | 应聘xx职位+姓名+学校 |
| 简历文件命名 | 应聘xx职位+姓名+学校 |
| 附件格式 | PDF |
| 邮件正文 | 礼貌称呼 + 简短自我介绍 + 明确求职意向 + 相关经验简述 |
| 发送时间 | 建议早上8:00-8:50发送 |

## 七、各模块通用写法示例

### 个人信息
```
姓名（大号加粗）| 求职意向（明确唯一）| 电话 | 专业邮箱
城市 | 出生年月（体制内加政治面貌、籍贯、性别）
```

### 教育背景
```
20XX-20XX | XX大学 | XX专业 | 本科/硕士
GPA：3.8/4.0（排名前X%）
主修课程：课程1、课程2、课程3（与目标岗位相关）
荣誉：校级优秀学生、XX奖学金
```

### 工作/实习经历
```
公司名称 | 岗位 | 20XX.XX-20XX.XX
- STAR描述1：在XX情境下，负责XX任务，采取XX行动，达成XX结果
- STAR描述2：……
（每段经历写2-3条bullet point，第一条必须是最核心业绩）
```

### 技能证书
```
专业技能：技能1（精通）、技能2（熟练）、技能3（了解）
资格证书：证书1、证书2（含获取年份）
语言能力：英语CET-6（XXX分）、普通话二甲
```

### 自我评价
```
3句话公式：
1. 专业背景+核心经验（X年XX行业XX岗位经验）
2. 核心能力+量化亮点（擅长XX，曾实现XX增长XX%）
3. 求职动机+岗位适配（期望将XX能力应用到贵公司XX业务）
```
